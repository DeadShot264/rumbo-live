# Rumbo · En directo

Página que muestra en un mapa un viaje compartido desde la app Rumbo.

Las posiciones llegan cifradas de extremo a extremo (AES-GCM) a través de ntfy.sh; la clave va solo en el enlace (detrás de `#`), así que ni este sitio ni ntfy.sh pueden leerlas. Aquí no se guarda ningún dato.
